## Vercel

`vercel.json` now explicitly sets the framework to `nextjs` and intentionally does not define `outputDirectory`. Keep Root Directory at the repository root and Output Directory on automatic detection.

## Model service

Do **not** deploy `model-service/` to the same Vercel project. Run it on a separate Docker-capable CPU/GPU host. Add these server-side variables to Vercel only after that service exists:

```env
MODEL_SERVICE_URL=https://your-model-service.example.com
MODEL_SERVICE_TOKEN=long-random-secret
```

The web app remains usable before these variables are configured; `/api/evaluate` returns 503 instead of breaking the test runner.
